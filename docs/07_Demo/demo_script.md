# Demo Script — 5–7 minutes

Use only after verifying that the described features work.

1. (0:00–0:30) Introduce the project and team.
2. (0:30–1:15) Explain the problem and MVP scope.
3. (1:15–2:00) Show the architecture and Socket.IO room model.
4. (2:00–4:30) Demonstrate two browser sessions, room joining, drawing, colour, clear, and participant presence.
5. (4:30–5:15) Explain tests run and show actual evidence.
6. (5:15–6:00) State limitations and future work.
7. (6:00–6:30) Briefly describe each member's actual contribution.

Replace this script if the real demo takes a different amount of time. Do not claim unimplemented features.
